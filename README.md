# Bassem Hussein — Personal Portfolio & Interactive Showcase

An award-winning personal portfolio website engineered as an interactive single-page application with advanced CSS 3D transforms, cinematic motion design, and a curated dark/light color system.

Designed for **Bassem Hussein**, Frontend Software Engineer specializing in **Angular (v17+ with Signals)**, **RxJS Reactive State Systems**, and **AI-Assisted Development**.

---

## 🌟 Key Features

1. **Cinematic Hero Experience**:
   - Animated CSS gradient mesh with floating ambient orbs reacting to mouse parallax.
   - 3D `rotateX` letter-by-letter staggered entrance animation for **Bassem Hussein**.
   - Dynamic typewriter rotator highlighting core engineering domains.
   - High-fidelity 3D tilt portrait frame with depth-separated floating credential badges.

2. **Interactive 3D Tilt System (`TiltCard.tsx`)**:
   - Hardware-accelerated CSS 3D perspective transforms (`rotateX`, `rotateY` capped at $\pm 10^\circ$).
   - Dynamic radial highlight sheen tracking cursor coordinates in real time.
   - Dynamic shadow elevation shift.
   - Automatic fallback for touch screens (`pointer: coarse`) and `prefers-reduced-motion`.

3. **Interactive Angular Architecture & RxJS Sandbox**:
   - **RxJS Stream Pipeline Simulator**: Visualizes debounced inputs, `distinctUntilChanged`, `switchMap`, and Signal state updates with live execution telemetry.
   - **SOLID Architecture Blueprint**: Interactive explorer of Core, Shared, and Feature lazy-loaded module structures modeled after the Egyptian Public Prosecution platform.
   - **Dynamic Reactive Forms Engine**: Code inspector showcasing custom asynchronous validators and cross-field legal validation.

4. **Featured Projects & Live Interactive Runner**:
   - **GDSC Educational Platform** (Live Angular 14+ / RxJS on GitHub Pages): Includes in-app interactive live sandbox frame (`LiveAppModal.tsx`) with Desktop/Tablet/Mobile viewports, reload controls, and direct links.
   - **CV Builder**: Dynamic Resume & Curriculum Vitae Creator using DOM/BOM manipulation, LocalStorage, and PDF export.
   - **EG-BANK**: Cards for Everyday Life & Online Banking portal with RegEx validation and search filters.
   - **IP Tracker APP**: Real-time geolocation & network intelligence query tool with interactive map pinning.
   - **HealthAI Egypt**: AI Medical Triage platform with live clinical triage simulator modal.

5. **Career History & Community Leadership**:
   - Interactive vertical timeline for **Intercom Enterprise**, **Etmana**, and **Nokia**.
   - 3D showcase cards for **GDSC Campus Lead at Cairo University** and **Microsoft Learn Student Ambassador**.

6. **Printable Curriculum Vitae (`ResumeModal.tsx`)**:
   - Formatted, ATS-friendly modal with one-click **Print / Save as PDF** support.

7. **Dark / Light Theme System**:
   - Persisted in `localStorage` and synchronized with system `prefers-color-scheme`.
   - 60-30-10 palette distribution adhering to high-contrast WCAG AA standards.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS v4 + Custom SCSS/CSS 3D perspective variables
- **Motion & Parallax**: Framer Motion (`motion/react`) with spring physics
- **Icons**: Lucide React
- **Typography**: Space Grotesk (Headings), Plus Jakarta Sans (Body), JetBrains Mono (Code/Telemetry)

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run TypeScript & lint verification
npm run lint

# Production build
npm run build
```
